# Shell, basics - Holberton School


Ce dossier contient les scripts Bash du projet 1 "Shell, basics", réalisant des opérations fondamentales sur le terminal Linux.



* **`0-current_working_directory`** : Affiche le chemin absolu du répertoire de travail actuel.

* **`1-listit`** : Liste le contenu du répertoire courant.

* **`2-bring_me_home`** : Change le répertoire courant vers le dossier personnel de l'utilisateur.

* **`3-listfiles`** : Liste le contenu du répertoire courant au format long.

* **`4-listmorefiles`** : Liste tous les fichiers (y compris masqués) au format long.

* **`5-listfilesdigitonly`** : Liste le contenu avec les UID et GID affichés sous forme numérique.

* **`6-firstdirectory`** : Crée un répertoire `/tmp/my_first_directory`.

* **`7-movethatfile`** : Déplace le fichier `betty` dans `/tmp/my_first_directory/`.

* **`8-firstdelete`** : Supprime le fichier `betty` dans `/tmp/my_first_directory/`.

* **`9-firstdirdeletion`** : Supprime le répertoire `/tmp/my_first_directory`.

* **`10-back`** : Revient au répertoire de travail précédent.

* **`11-lists`** : Liste les fichiers du répertoire courant, du répertoire parent et de `/boot` en format long.

* **`12-file_type`** : Affiche le type du fichier `/tmp/iamafile`.

* **`13-symbolic_link`** : Crée un lien symbolique `__ls__` pointant vers `/bin/ls`.

* **`14-copy_html`** : Copie les fichiers `.html` récents ou absents vers le répertoire parent.

* **`15-lets_move`** : Déplace les fichiers commençant par une majuscule vers `/tmp/u/`.

* **`16-clean_emacs`** : Supprime tous les fichiers temporaires se terminant par `~`.

* **`17-tree`** : Crée l'arborescence de dossiers `welcome/to/school`.
